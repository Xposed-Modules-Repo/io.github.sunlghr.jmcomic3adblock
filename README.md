# JMComic3 去广告

适用于 JMComic3 2.0.14（`com.JMComic3.app`）的 LSPosed 模块，可屏蔽开屏、首页、详情页和阅读器中的广告。模块不包含目标应用。

## 安装

1. 在本仓库的 Releases 下载并安装签名 APK。
2. 使用兼容 libxposed API 102 的 LSPosed 启用模块，并勾选 `com.JMComic3.app` 作用域。
3. 强制停止 JMComic3 后重新打开。

从 v1.1.3 或更早版本迁移时，请先停用旧模块。新版包名不同，不能覆盖安装，设置也不会自动迁移。
